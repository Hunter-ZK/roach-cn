# 蟑螂：面对与逃生（中文独立重制版）

一个无需构建、可直接部署到 GitHub Pages 的纯静态小游戏。

## 玩法

- **第一阶段：面对** — 点击/触摸蟑螂进行攻击，可切换不同工具；击杀 25 只后可进入下一阶段。
- **第二阶段：逃生** — 玩家变成蟑螂，使用虚拟摇杆移动，通过冲刺躲避人类，并尽量留下更多卵鞘。
- **标本图鉴** — 根据使用过的工具和第二阶段行为逐步解锁。

## 本地运行

直接双击 `index.html` 即可。若浏览器限制本地存储，也可以运行：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## GitHub Pages

本仓库已包含 GitHub Actions 自动部署配置。推送到 `main` 后会自动部署到 GitHub Pages。
